# v0.1.3

在 v0.1.2 的真实额度、套餐信息和面板修复基础上，合并凭据保护与生成流程优化。

## 修复与优化

- 管理密钥链接改为 `#key=`，避免密钥进入服务器访问日志；也可继续手动输入。
- 本机登录页校验 state，正确处理会话过期；修复浏览器扫描后无法导入的问题。
- 修复参考图上传使用空客户端的问题；多结果请求共用一次参考图上传。
- 复用代理/直连 HTTP 连接池，减少图像生成中的重复轮询。
- 避免宿主请求结果不确定时重放生成和 token 刷新 POST。
- 修复任务超时、取消、热更新后的并发限制和模型目录缓存问题。
- 修复流式响应分块 ID 不一致，以及签名 URL 经错误日志泄露的问题。
- 保留 v0.1.1/v0.1.2 的计费接口、实时余额、套餐及 RFC3339 任务时间修复。

## 验证

合并后通过完整功能测试、Go 竞态检测、`go vet` 和格式检查。构建产物由 GitHub Actions 生成并校验 ABI 导出。

详细说明见 [运行问题检查与优化记录](../runtime-review.md)。
