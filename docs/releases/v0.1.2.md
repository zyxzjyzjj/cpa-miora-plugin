# v0.1.2

面板细节收尾。

## 修复

- **进入账号页自动拉一次实时额度**：此前只在点「拉取实时额度」时才请求上游，首次打开永远是 `0 / 0`。
  现在进入账号页若还没有余额快照会自动拉取；仍未拉取时显示「额度未拉取」而不是误导性的 0。
- **导入账号后立即缓存余额快照**，卡片上直接显示剩余 / 总额 / 到期时间。
- 账号卡片显示套餐名（`tierName`，如 `Free`）与额度到期时间（来自 `nextExpiring.expiredAt`）。

## 沿用 v0.1.1

- 积分改走 `POST /api/miora-billing/credit` 与 `/api/miora-billing/subscription`。
- 任务时间改为 RFC3339 字符串，未完成的任务不再显示「739918 天前」。
