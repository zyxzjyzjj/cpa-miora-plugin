# v0.2.4

修复"生成台选不了模型、选不了比例"。

## 根因

0.2.2 给 `/models` 的响应里加了 agent 状态，而 `agentStatusView()` 先锁 `agentRuntimes.mu`，
接着调用 `knownAgentModels()`，后者**又去锁同一把 `sync.Mutex`**（不可重入）→ 自我死锁。
表现：

- `GET /v0/management/miora-provider/models` 永不返回；
- 面板拿不到模型目录 → 生成台的模型下拉、比例下拉、分辨率下拉全是空；
- 连带 `/status`、`/diagnostics` 也卡住。

## 修复

`agentStatusView()` 改为先在锁内拷贝运行时快照，**释放锁之后**再查模型目录。
新增回归测试 `TestAgentStatusViewDoesNotDeadlock`：3 秒内必须返回，否则失败。

## 验证（Windows + CPA v7.3.9）

| 接口 | 修复前 | 修复后 |
| --- | --- | --- |
| `/models` | 挂死（超时） | 200，0.29s，55 个模型 |
| 媒体分布 | — | image=24、video=12、three_d=6、chat=12 |
| 图像模型能力 | — | `hy-image-3.5-f`：14 种比例、1K/1.5K/2K |
| `/status` | 挂死 | 200，0.05s |
| `/diagnostics` | 挂死 | 200，0.53s |

另外把面板内联脚本跑了 `node --check`，语法通过（39 KB）。
