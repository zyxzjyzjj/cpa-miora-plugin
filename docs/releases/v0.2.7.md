# v0.2.7

修复 0.2.6 的"记忆轮转没生效"。

## 问题

0.2.6 在一轮超过 `agent_max_prompt_tokens` 后只清了内存缓存与状态文件，
但运行时仍会从候选项目里**把同一个老项目重新选回来**（`rememberedProjects` 与
`findAgentProjects` 都还认得它），结果实测：

```
chat #1  prompt_tokens=314330   memory budget reached, rotating project
chat #2  prompt_tokens=383457   ← 记忆不但没清，还更大
```

## 修复

- 状态文件新增 `retired_projects`：被轮转掉的项目进入黑名单，候选遍历直接跳过；
- `retireProject()` 同时清 `rememberedProjects`、状态条目，并落盘；
- 黑名单最多保留 20 个，避免无限增长。

## 预期效果

轮转后下一轮会新建项目（沙箱冷启动一次），prompt 回到约 **4.9 万** 的基线，
之后每轮按需增长，超过预算再轮转一次。
