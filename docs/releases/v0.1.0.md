# v0.1.0

首个可用版本：把 Miora 的图像 / 视频 / 3D 生成反代为 OpenAI 兼容模型，作为 CLIProxyAPI 原生插件运行。

## 能力

- `auth_provider`：本机 Edge / Chrome 登录态一键导入、手动粘贴、CPA 原生登录页；`refresh_token` 一次性轮换并自动写回 auth 文件。
- `model_provider`：上游目录 42 个模型（图像 24 / 视频 12 / 3D 6），含比例、分辨率、参考图上限与可用性；支持前缀、白/黑名单、离线静态表与 `miora-auto` 兜底。
- `executor`：`/v1/chat/completions` → 提交 / 轮询 / 签名 → Markdown 媒体 + `miora` 结构化扩展；流式给进度；支持 `aspect_ratio`、`size`、`resolution`、`duration`、`n`、`family` 与 `miora://file/...` 参考图。
- `quota_provider` / `usage_plugin` / `scheduler`：真实余额、请求日志、多账号轮转。
- `management_api` + 控制台：概览 / 账号 / 生成台 / 产物 / 模型 / 日志 / 设置 / 自检，中文界面，内联样式与脚本（不引第三方 CDN）。

## 端到端验证（2026-10-30，Windows amd64 + CPA v7.3.9）

| 项 | 结果 |
| --- | --- |
| 插件注册 | `registered=true`、`effective_enabled=true`、`supports_oauth/quota=true` |
| 模型注册 | `/v1/models` 可见 43 个（42 + `miora-auto`） |
| 文生图 | `hy-image-3.5-f` 15.8s，PNG 2.3MB，产物 URL HTTP 200 |
| 流式 | 13.8s，`role → 进度 → 内容 → [DONE]` |
| 浏览器导入 | Edge `Default` 命中有效登录态；失效 token 被标红 |
| 管理路由 | 账号 / 模型 / 生成 / 任务 / 产物 / 重签 / 设置 / 自检 全通 |

## 已知限制

- 不提供 chat 反代：Miora 的 LLM 是有状态 ACP Agent，需要人工审批工具调用，无状态转换不存在。
- `upload_reference_images`（COS 直传）为实验特性，默认关闭；关闭时请传 `miora://file/...`。
- 免费档 `/api/ai/quota/credit` 常返回 0，额度以任务结果与日志中的扣费字段为准。
- 历史问题已修复：auth `Attributes.base_url` 会让宿主改用内置兼容链路直连上游（表现为 `405 Not Allowed`），现留空。
