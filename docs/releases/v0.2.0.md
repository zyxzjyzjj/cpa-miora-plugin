# v0.2.0

Agent 对话模型接入：`deepseek-v4.1-flash`、`glm-5.3`、`kimi-k3`、`gpt-6-astra`、`gpt-5.6-sol`、`gemini-3.8-flash` 等现在和媒体模型共用 `/v1/chat/completions`。

## 新增

- **ACP 桥**：`POST /api/ai/cloud-agent/runtimes` → `{acpLink.url}/bootstrap`（HTTP + SSE），
  方法链 `initialize` → `session/new` → `session/load` → `session/set_model` → `session/set_mode` → `session/prompt`。
- **模型注册**：`cloud-agent/tiers` 的 Agent 目录并入 `/v1/models`（`type=chat`），
  运行时用 `availableModels` 自动补全；`agent_models` 可追加。
- **流式**：`agent_message_chunk` 增量经合并协程写入宿主流；`usage` 取自 prompt 结果的真实 token 数。
- **生命周期**：运行时按账号缓存、每轮刷新 ACP token、绑定失效时自动重建；
  每轮独立 `session/new` 并在结束后异步 `session/close`；同账号串行，避免沙箱排队。
- **配置**：`agent_enabled`、`agent_default_model`、`agent_models`、`agent_project_id`、
  `agent_project_title`、`agent_mode`、`agent_timeout_seconds`、`agent_runtime_ttl_minutes`。

## 端到端实测（Windows amd64 + CPA v7.3.9）

| 场景 | 结果 |
| --- | --- |
| 非流式 `deepseek-v4.1-flash` | 200，29.8s（含冷启动），`usage={prompt:49473, completion:137}` |
| 热启动再问 | 200，8.9s |

| `/v1/models` | 55 个（42 媒体 + 13 Agent） |

## 已知行为

- 冷启动 10–30s；Agent 自带大系统提示词，每轮 `inputTokens` 4.9 万起。
- 同一项目下上下文累积（站点本身设计）；隔离请用不同 `agent_project_id`。
- 一个沙箱同时只服务一个会话，插件按账号串行化。
- 工具审批用 `bypassPermissions`；若改成需要审批的模式，遇到工具调用会明确报错而不是静默卡住。
- 本版本已合并上游 v0.1.3 的凭证保护与生成生命周期修复。
