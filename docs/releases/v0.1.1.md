# v0.1.1

修两个面板上看得见的问题。

## 修复

- **积分显示 0（实际 250）**
  之前读的是 `/api/ai/quota/credit`（免费档恒为 0）。改为读计费服务：
  `POST /api/miora-billing/credit` → `{totalAmount, usedAmount, nextExpiring}`，
  `POST /api/miora-billing/subscription` → `{tierCode, tierName, creditTotal, creditLeft}`。
  面板现在显示真实余额、套餐名（如 `Free`）与额度到期时间（如 `2027-01-30 15:51:36`）；
  旧接口保留为兜底。

- **进行中的任务显示「739918 天前」**
  任务记录的时间字段原来是 `time.Time`，零值序列化成 `0001-01-01T00:00:00Z`，
  前端算差值就成了 73 万天。现在服务端只在已知时输出 RFC3339 字符串
  （`finished_at` 未完成时不下发），前端也加了 `year < 2000` 的兜底，
  未完成的任务显示基于 `started_at` 的相对时间。

## 已知限制（未变）

- 不提供 Agent 对话反代：Miora 的 Agent 是**项目级 ACP（WebSocket）**，每次需要
  `runtimeId` + `acpLink` 临时令牌，并且工具调用要经 `/api/ai/tool-confirmation/*` 审批。
  插件当前只反代无状态的媒体生成接口；Agent 档位（deepseek 等）不在模型列表里。
- `upload_reference_images`（COS 直传）仍为实验开关，默认关闭。
